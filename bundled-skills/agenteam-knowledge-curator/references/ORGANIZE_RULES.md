# 整理规则

本文件决定整理 Agent 如何为这个知识库的资料生成摘要、标签和分类。你可以随时修改；下一轮整理按修改后的内容执行。

## 分类体系

分类是资料在知识库界面中的虚拟文件夹，使用 `/` 分隔层级。整理 Agent 只会使用下面列出的分类；需要新分类时，它只能提出建议，由你在知识库界面确认后才会加入。

每行一个分类，格式为 ``- `分类路径`：说明``：

- `参考资料`：手册、规范、教程、白皮书等长期参考的资料
- `项目`：与具体项目相关的方案、进展、交付物
- `会议记录`：会议纪要、讨论记录、访谈记录
- `合同与协议`：合同、协议、报价单、条款
- `报告`：分析报告、周报、调研结果
- `其他`：暂时无法归类的资料

## 标签

- 标签是平铺的关键词，用于跨分类检索。每份资料 3–8 个。
- 优先复用已有标签；同义标签只保留一个（例如"客户"和"顾客"选一个）。
- 使用名词或名词短语，不使用整句。

## 文档类型

可选值：`合同`、`报告`、`会议纪要`、`方案`、`手册`、`论文`、`表格`、`演示文稿`、`笔记`、`其他`。

## 摘要

- 每份资料 1–3 句话，说明它是什么、讲了什么、对谁有用。
- 摘要只陈述资料中的内容，不加评价。
