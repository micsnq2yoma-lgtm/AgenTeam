# Wiki 规则

本文件决定整理 Agent 如何维护这个知识库的 wiki。wiki 是在原始资料之上的一层主题综述，帮助你和 Agent 快速了解知识库的全貌。你可以随时修改本文件。

## 页面

| 页面 | 作用 |
|---|---|
| `index.md` | 知识库总览：用途、主要主题列表（链接到各主题页）、最近更新 |
| `topics/<主题>.md` | 一个主题一页，综合多份资料的内容 |
| `log.md` | 每轮整理的变更记录，只追加 |

主题页文件名使用简短的名词短语，例如 `topics/产品定价.md`。

## 主题页结构

```markdown
# <主题名>

<一段话概述这个主题>

## 要点

- <结论>。[来源](kb://<kb-id>/<source-id>#<chunk-id>)

## 相关主题

- [<主题名>](<主题文件名>.md)

## 待确认

- <资料之间的矛盾、过时信息或缺口>
```

## 引用

- 每一条结论都必须带至少一个 `kb://` 引用，指向支持它的原始资料片段。没有引用的内容不写入 wiki。
- 只引用原始资料，不引用其他 wiki 页面作为证据。
- 资料之间矛盾时，在"待确认"中并列写出各方说法和引用，不擅自判断对错。

## 链接

- wiki 页面之间使用相对路径的 Markdown 链接，例如 `[产品定价](产品定价.md)`。
- 新建主题页后，在 `index.md` 中加入链接；不留下没有任何页面链接到的孤立页面。

## 日志

每轮整理在 `log.md` 末尾追加一条：

```markdown
## <YYYY-MM-DD>

- 新增：<页面>（<原因>）
- 更新：<页面>（<原因>）
- 待确认：<数量> 项
```
