- 验收日期为 2026-11-22。
- 基于远端 main 的 `7fe769a0ee083df7088f9b2bdf26796dfbef190f` 构建 AgenTeam `0.6.8` 原生 Tauri 桌面 App。在 Ubuntu 24.04、Xvfb 和新系统用户的独立 HOME 下运行。系统技能版本为 `71`，App 二进制 SHA-256 为 `0361559f7695738e997d42c0c99769d2b44a5a7614ad42f39be353a8da61dd0d`。
- 使用 DeepSeek V4.1 Flash（`deepseek-flash`，内置 Claude Agent SDK `0.3.330`）及 GPT-6.2-Sol（App 的系统 Codex CLI `0.167.0`，以 ChatGPT 订阅登录）。内置托管订阅在此环境无 Linux 平台包。两条运行路径均在桌面会话产生真实模型回复。
- 项目、对话、简历、网页及提醒事项均为合成夹具。验收未修改产品代码。下文十六进制摘要均为 SHA-256，带省略号的值为前缀。

## 阻塞项

- V7 真实心跳投递及关闭后停止投递需要独立测试 Bot 和实际私聊接收端。本轮隔离 HOME 未配置这些依赖。
- V8 没有配置邮件或日历 MCP，Ubuntu 环境也没有 macOS icalBuddy。不能验证真实邮件或会议内容读取、缺源提示在真实 IM 中只出现一次、外部注入和无外发动作。
- V9 没有独立测试 Bot，不能验证同类真实通知的一次或两次反馈、规则写入与撤销说明，也不能验证外部 IM 消息尝试关闭或清空规则的拒绝行为。
