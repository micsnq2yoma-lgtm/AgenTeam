# A2 BOOTSTRAP 收集资料与结果回到聊天：自检记录

分支 `dev/assistant-a2-bootstrap`，基于 A1 分支。自检不是独立验收；AC-A2-2、3、4 需要真实 App 和模型，本环境无法运行，标为**未验证**。

## 交付

- `/BOOTSTRAP` 在确定名字和风格之后新增"Get To Know Them (optional)"：轻量询问是否愿意提供资料；跳过就不创建任何东西；给了资料就按 `CLAUDE.md` 交给后台 Task，并继续本次对话。BOOTSTRAP 对 `03-USER.md` 只填"基本信息"章节。
- atmer `CLAUDE.md` 新增"Know Your Human"：什么时候创建画像 Task（首次给资料、更新、更正；没有资料也没有更正就不创建）、怎么创建（自包含的 `workspace/profile-task.md`，`myagents task create-direct … --executionMode once` 后 `myagents task run`）、Task 结果回到聊天后的消息格式（一两句理解、一条具体观察、一件可接手的事、有矛盾就询问，不贴报告、不引用原文）、读取范围（只读用户给的）。
- 这些规则放在 `CLAUDE.md` 而不是 BOOTSTRAP，因为 BOOTSTRAP 做完会删除自己，而 Task 结果要稍后才回来，之后的"更新画像"和"更正"也要用同一套流程。
- "记忆维护"里"新认识就更新 `03-USER.md`"改为"在 近期观察 下追加带日期的一行"，与章节归属一致（A3 的 Skill 侧规则另行实现）。

## 偏离规格之处

- 规格写 `--executionMode once --runMode new-session`。`once` 模式会强制使用新会话，且 `--runMode` 不在 `task create-direct` 的 leaf help 中，所以命令里去掉了 `--runMode`。
