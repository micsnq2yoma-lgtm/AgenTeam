# A3 记忆 Skill 的章节归属与预算：自检记录

分支 `dev/assistant-a3-memory-sections`，基于 A2 分支。自检不是独立验收；AC-A3-3 需要真实 App 和模型，本环境无法运行，标为**未验证**。

## 交付

- `agenteam-memory-update`：USER 文件使用固定章节时，关于用户的新认识只追加到"近期观察"（一条一个事实、带日期、去重）；用户的更正本身写进"近期观察"并注明推翻了什么；用户明确更正名字、称呼、语言、时区时可直接改"基本信息"；其余章节归画像 Task 和 Gardener。旧式 USER 文件（没有"近期观察"）沿用原做法。
- `agenteam-memory-gardener`：新增"USER 画像的整理"：把"近期观察"里明确或反复验证的条目并入对应章节并删除该条，归属不明的留在原处，用户更正优先，只改并入的那几处、章节标题与顺序不变、不改"来源概况"；这是画像 Task 之外唯一整理主体章节的入口。报告格式和自检清单同步增加。旧式文件沿用原整编方式。
- `memory_lint.py`：新增 `observations` 检查：固定章节结构的 USER 文件，"近期观察"超过 20 条给 WARN，否则 INFO；没有该章节的旧式文件不产生任何此项输出；围栏代码内和其他章节的条目不计入。
- `SYSTEM_SKILLS_VERSION` 升到 68（TS 与 Rust）。

## 偏离规格之处

- **预算沿用 20 KB**：规格写明本任务不改阈值，脚本的 USER 预算保持 20 KB，方案里的 6 KB 目标只写在画像 Skill 里作为篇幅建议，待用户另行决定是否收紧。
