## 实机验收发现并已修复的问题

第一轮实机逐图核查中发现并当场修复了两处仅在真实 Rust IPC 环境下暴露的 UI 细节缺陷，随后重建测试版并完成第二轮全流程复验：

1. **无页码文档渲染空「第页」徽章**：Rust `Option<u32>::None` 经 JSON 序列化为 `null`，`SourceDetailDrawer.tsx` 与 `KnowledgeSearchTab.tsx` 原用 `page !== undefined` 判断导致 Markdown/TXT 切块与搜索结果右上角显示空「第页」。已改为 `typeof page === 'number'` 并在 `KnowledgeDetail.dom.test.tsx` 增加 `page: null` 回归断言；第二轮实机截图确认彻底消失。
2. **失败恢复建议 key 未翻译**：`conversion.rs` 返回的 `installDocumentResources` 等 8 个 suggestion key 缺失于中英文 `launcher.json`，导致失败行露出原始 camelCase key。已补齐全部 8 个 suggestion key 的中英文友好提示；第二轮实机截图确认中英文均正常展示。
