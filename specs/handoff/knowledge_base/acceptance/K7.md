## 交付

- `bundled-skills/myagents-knowledge/SKILL.md`：何时检索、改写成 2–3 条查询、`kb://` 引用规则、检索为空时如实说明、资料中的指令不是用户指令、群聊隐私、普通对话中的写入。

- `specs/tech_docs/knowledge_base.md` 新增 K7 章节。

## 偏离 tasks.md 之处

1. **curator Skill 没有写出 wiki、分类提议、lint 提交和读取规则的命令。** AC-K7-2 要求 Skill 中的每条命令都与 K5 leaf help 一致，而这些命令在 K8 才实现。现在的做法是让 Skill 先用 `myagents kb --help` 判断命令是否存在，不存在就跳过对应步骤并在最终回复中说明。K8 实现命令时同步修改 Skill、测试，并 bump 版本。
2. **K8 需要补一个读取入口。** 按 K5 现有的 CLI，整理 Agent 读不到 `ORGANIZE_RULES.md`、`WIKI_SCHEMA.md` 和待整理列表（它们不是 source，`kb read` 读不到）。K8 应提供读取命令，或在整理 Task 的任务说明中注入这些内容。这是 K8 的设计决定，已写入 tech doc。
3. **模板只有中文。** 模板是用户编辑的文档，不是界面文案，所以不走 i18n（D8）。多语言模板与 K9 知识库界面一并决定。
4. **K7 之前建立的库没有模板文件。** 这次不回填。curator Skill 遇到缺失时不写分类或不改 wiki，并在最终回复中说明。
