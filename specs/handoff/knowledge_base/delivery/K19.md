## 1. 交付范围与实现

1. **SSRF 安全抓取与 HTML → Markdown 提取（Rust）**
   - [url_import.rs](file:///E:/ArmBuild/kb-k9/src-tauri/src/knowledge/url_import.rs) & [tests.rs](file:///E:/ArmBuild/kb-k9/src-tauri/src/knowledge/url_import/tests.rs)：
     - 协议白名单仅放行 `http://` 与 `https://`，拒绝 `file://`、`ftp://`、`data:`、`javascript:` 与含凭据 URL；
     - 与 `egress_restriction::public_ip` 对齐的 `is_public_global_ip` 覆盖 IPv4/IPv6 环回、私有、链路本地、CGNAT、ULA 与 IPv4-mapped 地址；

     - `extract_html_to_markdown` 过滤脚本/样式/导航/页脚与危险链接，提取正文并交由 `KnowledgeIngestManager` 标准摄取入库。
