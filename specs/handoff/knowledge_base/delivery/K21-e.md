# K21-e 交付报告：限制模式（出口 IP 核验）与规范文档同步

## 1. 本步改动清单（对照 `online-embedding.md` §5.6）

- **`src-tauri/src/knowledge/online_embedding.rs`**：
  - 新增 `KnowledgeEmbeddingService::admit_embedding_egress()`，在每批在线嵌入（入库批量与检索查询嵌入）发出任何 HTTP 请求之前，顺序执行：
    1. `crate::proxy_config::ensure_model_egress_admitted()`（当前主机出口门禁）；
    2. `crate::egress_restriction::fresh_exit_ip(Duration::from_secs(3))`（要求 3 秒内新鲜出口 IP 证据）。
  - 任一检查不通过均立即返回 `EmbeddingErrorKind::EgressBlocked`（入库批失败、检索自动降级为 `mode: "bm25"` + `degradedReason: "egress_blocked"`，不发任何出站 HTTP 请求）。
- **`src-tauri/src/knowledge/online_embedding/tests.rs`**：
  - 新增离线单测 `restricted_mode_rejects_embedding_batch_before_any_http_call`，验证限制模式拒绝时 `embed_batch` 与 `embed_query` 均返回 `EmbeddingErrorKind::EgressBlocked` 且对本机回环 mock 服务端发出 0 次 HTTP 请求。
- **`specs/tech_docs/proxy_config.md`**：
  - 更新「出口 IP 限制模式」一节，如实记录知识库在线嵌入在 Rust 侧执行每批前 `ensure_model_egress_admitted()` + `fresh_exit_ip(3s)` 核验、不满足时失败并降级 BM25，以及 Rust 侧不包含 Node `admitModelTurn` 的 `/cdn-cgi/trace` 域名核验层（仅具备前两层核验）。
