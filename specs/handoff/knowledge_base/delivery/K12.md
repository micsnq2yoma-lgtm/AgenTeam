## 交付：K12 linked folder、watcher 与移动识别

- 分支 / 基线：`feat/kb-k12-linked-folder`，基于最新 `origin/main`（`db981d88`，已合入全部 P0 K0–K11）
- 改动概述：
  - **Store 持久化模型与事务（`src-tauri/src/knowledge/store/linked.rs`、`store.rs`、`store/chunks.rs`）**：在 `kb.json` 新增 `linkedFolders[]`（含 `path`、`organizeAllowed` 默认 `false`、`gitConfirmed` 默认 `false`、`isGitWorkTree` 向上检测 `.git` 目录/工作树文件）；在 `SourceRecord` 为 `SourceKind::LinkedFile` 记录 `LinkedSourceMeta`（`folder_root`、`original_sha256`、`extension`、`content_revision`），不复制 `original.<ext>`；实现 `add_linked_folder`、`update_linked_folder`、`remove_linked_folder`、`list_linked_sources_for_folder`、`publish_linked_source`、`relink_moved_source`、`refresh_linked_fingerprint`，并在 `resolve_preview_target` 支持 `LinkedFile` 经 no-follow 校验直达用户原件或回退 `content.md`。
  - **安全扫描、对账移动识别与去抖 watcher（`src-tauri/src/knowledge/linked.rs`）**：复用 `search::file_indexer::SKIP_DIRS`，默认排除隐藏目录/文件与凭据类文件；每层拒绝符号链接、Windows NTFS junction 与重解析点，叶文件经 `open_workspace_regular_file_no_follow_classified` 做有界读取与读后二次元数据校验；按指纹或 `original_sha256` 识别外部移动/改名及 Windows/macOS 仅大小写重命名，只更新 `source.json` 路径而不重新切块、不递增 `content_revision`；`KnowledgeLinkedManager` 使用 `notify_debouncer_full` 监听变更并在退出时清理。
  - **跨平台路径归一化**：剥离 Windows `\\?\` 与 macOS APFS `/System/Volumes/Data` firmlink 前缀，按平台大小写语义匹配路径键。
  - **Tauri 控制面与共享类型**：在 `commands.rs` / `lib.rs` 注册用户专属命令 `cmd_kb_add_linked_folder`、`cmd_kb_remove_linked_folder`、`cmd_kb_update_linked_folder`、`cmd_kb_scan_linked_folder`（不暴露给 Management API / CLI），并同步更新 `src/shared/knowledge/index.ts`、`src/renderer/features/knowledge/types.ts` 与 `specs/tech_docs/knowledge_base.md`。
