## 2. K21-0 TokenDance 网关实测结果

使用本机已登录 TokenDance 账号的 API Key 对 `https://tokendance.space/gateway/v1` 进行实测（未打印任何密钥）：

- **`GET /gateway/v1/models`**：成功返回 OpenAI 兼容列表，包含 2 个向量模型条目：
  - `qwen-text-embedding-v4`（`name: "Qwen: Text Embedding V4"`，`context_length: 8000`，`supported_protocols: ["openai:embeddings"]`，支持 64~2048 维自定义维度）
  - `qwen3.7-text-embedding`（`name: "Qwen: Qwen3.7 Text Embedding"`，`context_length: 128000`，`supported_protocols: ["openai:embeddings"]`，支持 256~2560 维自定义维度）
- **`POST /gateway/v1/embeddings`**（`model: "qwen-text-embedding-v4"`，`dimensions: 1024`）：网关路由生效（非 404/405），在当前零余额测试账号上返回 `HTTP 402 Payment Required`（耗时 `3287 ms`），直接验证了 `/embeddings` 端点已上线以及 `402` 余额不足错误映射的必要性。

## 3. 本步改动清单

### 后端（Rust）
- 新增 `src-tauri/src/knowledge/online_embedding.rs` 与 `src-tauri/src/knowledge/online_embedding/tests.rs`：
  - `EmbeddingModelConfig`（对应 `config.json` 中 `embeddingModel`：`enabled` / `providerId` / `model` / `dimensions`），每次调用直接从磁盘实时读取，不缓存陈旧配置。
  - `preset_openai_embedding_base_url`：内置 `tokendance`（`https://tokendance.space/gateway/v1`）及主流 OpenAI 兼容供应商预设地址，并支持从 `<data_dir>/providers/*.json` 读取自定义供应商 `baseUrl`。
  - `validate_embedding_base_url`：强制仅允许 `https://` 或回环地址 `http://`（`127.0.0.1` / `localhost` / `::1`），拒绝内嵌凭据与任何 HTTP 重定向（`Policy::none()`）。
  - 外部端点走 `proxy_config::build_client_with_proxy_for_provider`（自动经过代理与出口策略）；回环端点走 `local_http::builder()`。
  - 完整错误脱敏与重试策略：429（解析 `Retry-After`）与 5xx 指数退避最多 5 次；`401`/`403`（`auth_failed`）与 `402`（`insufficient_balance`）绝不重试；错误与日志绝不输出 API Key、文本块或查询正文。
  - 向量 L2 归一化并复用 `quantize_l2_int8` 量化，生成确定性 `model_revision`（`online_<host>_<model>_<dim>`）。
- `src-tauri/src/knowledge/commands.rs` / `src-tauri/src/lib.rs`：注册 `KnowledgeEmbeddingService` managed state 与 `cmd_kb_test_embedding_connection` 命令。

### 前端（TypeScript / React）
- `src/shared/config-types.ts`：新增 `EmbeddingModelConfig`、`ModelCategory = 'chat' | 'embedding'` 及 `ModelEntity.category?`（不修改 `MODEL_PROTOCOL_PRIORITY`，不向静态 `TOKENDANCE_MODELS` 塞入嵌入模型）。
- `src/renderer/config/services/modelDiscoveryService.ts` + `modelDiscoveryService.tokendance.test.ts`：新增 `classifyDiscoveredModelCategory` / `isEmbeddingDiscoveredModel` / `fetchProviderEmbeddingModels`，复用同一 `modelListUrl` 发现 `id` 含 `embedding` 的模型，且单测回归验证对话模型发现结果完全不变。
- `src/renderer/pages/settings/components/EmbeddingModelCard.tsx` + `EmbeddingModelCard.test.tsx` + `SettingsPage.tsx` + `zh-CN`/`en-US` `settings.json`：
  - 模型设置页新增「知识库在线嵌入模型」卡片。
  - 已登录 TokenDance 时默认免配置选中 TokenDance，运行时拉取向量模型列表并优先推荐 `qwen-text-embedding-v4`（默认维度 `1024`）；拉取失败显示「无法获取向量模型列表」并支持手动输入；未登录 TokenDance 时给出清晰非报错提示。
  - 支持任意自定义 OpenAI 兼容供应商、隐私与按供应商计费说明、「测试连接」（自动回填实际维度）、以及 `401`/`402`/`404`/`429`/`5xx`/限制模式错误提示。
