# K21-b 交付报告：导入后置在线嵌入阶段接线

## 1. 本步改动清单

### 后端（Rust）
- `src-tauri/src/knowledge/vector_index.rs`：
  - 新增 `current_entries`、`upsert_source_entries`、`remove_source_entries`、`cleanup_stale_revisions`。
  - 发布新版本 `model_revision` 且原子更新 `active.json`（单调 `generation`）成功后，自动清理旧版本目录。
- 新增 `src-tauri/src/knowledge/ingest/embedding_stage.rs` 与 `src-tauri/src/knowledge/ingest/embedding_stage/tests.rs`：
  - 由 `KnowledgeIngestManager` 持有 `EmbeddingStage` 队列与状态，不另起新调度器或进程类型。
  - 状态机独立记录：`pending | embedding | ready | failed | skipped`，含 `embeddedChunks / totalChunks`、`estimatedTokens`、`modelRevision`、`errorKind`。
  - 批处理上限：每批 `<= 64` 块且总字符数 `<= 100,000` 字符（单块截断到 16,000 字符），并发度 `EMBED_CONCURRENCY = 2`。
  - 缓存复用与重启幂等续跑：按 `(model_revision, chunk_content_hash)` 命中 `KnowledgeVectorIndex::lookup_cached` 时直接复用已有量化向量，重启续跑对已嵌入块发出 0 次 HTTP 请求。
  - 切换模型 / 地址主机 / 维度时自动按库级新版本重嵌并原子切换 `generation`，切换成功后删除旧版本目录。
  - `401`/`403`（`auth_failed`）与 `402`（`insufficient_balance`）立即中止本轮剩余批次并置为 `failed`，不重试。
  - 删除资料（`cmd_kb_remove_source`）或删除库（`cmd_kb_delete`）时立刻取消待处理/进行中的嵌入批次并清理对应向量条目。
- `src-tauri/src/knowledge/ingest.rs` / `commands.rs` / `lib.rs`：
  - 资料 `finish_chunking` 进入 `Ready` 后自动触发 `EmbeddingStage::spawn_source`；启动 `recover()` 时自动触发 `spawn_resume_all()`。
  - 新增 Tauri 命令：`cmd_kb_embedding_summary`、`cmd_kb_source_embedding_status`、`cmd_kb_retry_embedding`。

### 前端（TypeScript / React）
- `src/renderer/features/knowledge/types.ts` + `knowledgeClient.ts`：新增 `SourceEmbeddingStatusKind`、`SourceEmbeddingProgress`、`LibraryEmbeddingSummary` 与 3 个调用封装。
- `src/renderer/features/knowledge/SourceDetailDrawer.tsx`：展示单资料向量嵌入状态、`已嵌入 X / Y 块`、错误原因与「重试嵌入」按钮。
- `src/renderer/features/knowledge/KnowledgeSettingsTab.tsx`：展示库级已嵌入块数 / 总块数、估算 token 数、当前模型版本与「重新嵌入」按钮（按最新 §5.4 规定，不设确认弹窗）。
- `src/renderer/i18n/locales/{zh-CN,en-US}/launcher.json`：补充中英文嵌入状态文案。
