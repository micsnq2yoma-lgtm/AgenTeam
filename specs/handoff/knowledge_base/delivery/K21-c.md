# K21-c 交付报告：混合检索接线、RRF 融合与降级展示

## 1. 本步改动清单

### 后端（Rust）
- `src-tauri/src/knowledge/online_embedding.rs`：
  - 新增 `KnowledgeEmbeddingService::embed_query(query, timeout)`（默认硬超时 `5s`，0 重试，保证检索延迟不会因嵌入超时超过 5 秒）与 64 条容量的有界 LRU 查询向量缓存（缓存键对查询文本做 SHA-256 哈希，不保存查询明文）。
  - 新增 `EmbeddingErrorKind::as_str()` 用于稳定输出 `degraded_reason`。
- `src-tauri/src/search/knowledge_indexer.rs` + `src-tauri/src/search/mod.rs`：
  - `KnowledgeSearchResult` 新增可选字段 `degraded_reason`（JSON `degradedReason`）。
  - `SearchEngine` 自动挂载 `Arc<KnowledgeVectorIndex>` 与 `Arc<KnowledgeEmbeddingService>`，所有检索入口（`cmd_kb_search`、`cmd_kb_global_search`、`management_api` CLI 检索）统一走 `search_hybrid`。
  - `search_hybrid` 流程：BM25 召回 → 校验在线嵌入可用性与库内向量 → `embed_query(5s)` → `KnowledgeVectorIndex::search_top_k`（并叠加 `category`/`tag`/`docType` 过滤）→ `fuse_bm25_and_vector_rrf` 返回 `mode: "hybrid"` 与真实 `bm25_hits` / `vector_hits`；任何失败均降级为 `mode: "bm25"` + `degraded_reason`，绝不让检索命令报错。
- `src-tauri/src/knowledge/commands.rs`：修复 `cmd_kb_search` 不再覆盖已由混合检索填充的 `bm25_hits`。
- 新增端到端测试 `src-tauri/src/search/knowledge_indexer/hybrid_tests.rs`：
  - 导入 Markdown → 在线嵌入落盘 → 零关键词重合的同义词查询返回 `mode: "hybrid"`（BM25 为空，向量命中 1 条，RRF 融合召回）→ 重复查询命中 LRU 缓存（0 额外 HTTP 请求）→ 密钥错误（401）或关闭开关时自动降级 `mode: "bm25"` + `degraded_reason` 且不报错。

### 前端（TypeScript / React）
- `src/renderer/features/knowledge/types.ts`：`KnowledgeSearchResult` 新增 `degradedReason?: string`。
- `src/renderer/features/knowledge/KnowledgeSearchTab.tsx` + `{zh-CN,en-US}/launcher.json`：展示 `degradedReason` 标签；三列对比（BM25 / 向量语义 / RRF 混合）渲染真实后端返回的三路命中。
