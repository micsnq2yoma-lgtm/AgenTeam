# 产品多语言术语对照表

## Core Terminology Glossary 核心术语表

| English Term | 简体中文译名 | Usage Notes 使用说明 |
| --- | --- | --- |
| Workspace | 工作区 | 对应一个本地项目目录及其配置边界 |
| Session | 会话 | 一次独立的对话上下文与权限快照 |
| Knowledge Base | 知识库 | 托管资料、切块索引与 Wiki 的集合 |
| Curator Agent | 整理 Agent | 负责元数据标注与 Wiki 维护的专用智能体 |
| Citation Chip | 引用标签 | 对话气泡中可悬停和跳转原文的 `kb://` 胶囊 |

## Formatting Consistency 排版规范

中文界面中阿拉伯数字与拉丁专有名词两侧保持单个半角空格，专有名词如 `PDF`、`Markdown`、`Tantivy`、`OAuth` 保持标准大小写，不翻译为中文音译。
