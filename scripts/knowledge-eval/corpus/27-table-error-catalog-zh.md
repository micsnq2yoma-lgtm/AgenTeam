# 平台统一错误码目录

## 常见错误码与处置建议表

| 错误码 | HTTP 状态 | 触发场景 | 客户端推荐动作 |
| --- | --- | --- | --- |
| `AUTH_TOKEN_EXPIRED` | 401 | 访问令牌已超过有效期 | 使用刷新令牌静默换取新凭据后重试 |
| `TENANT_SUSPENDED` | 403 | 租户欠费或触发合规冻结 | 停止自动重试并引导管理员查看账单中心 |
| `PAYLOAD_TOO_LARGE` | 413 | 单次上传文件超过 32 MiB 限制 | 提示用户拆分文件或压缩附件 |
| `UPSTREAM_TIMEOUT` | 504 | 依赖下游在 15 秒内未返回 | 带抖动指数退避重试最多三次 |

## 错误消息脱敏规范

所有对外返回的错误负载只允许包含稳定错误码、可本地化的提示键以及用于排障的 `requestId`，严禁暴露内部 SQL 片段、服务器内网 IP 或堆栈路径。
